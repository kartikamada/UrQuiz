# UrQuiz

UrQuiz adalah aplikasi kuis yang dikembangkan menggunakan React.js untuk memenuhi persyaratan pendaftaran magang DOT Indonesia pada posisi Front-End engineer.

## Tech Stack

Aplikasi dikembangkan menggunakan bahasa Javascript dengan _framework_ React.js versi 18.3.1.

## Instalasi

1. Clone repositori ini
2. Install dependensi menggunakan `npm install`
3. Build project menggunakan `npm run build`. Atau, jalankan project secara langsung dalam mode _development_ menggunakan `npm run dev`.
